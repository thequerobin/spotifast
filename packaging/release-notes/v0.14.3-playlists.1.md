Spotifast 0.14.3-playlists.1 is a Windows x64 preview of this fork's playlist generators. Create playlists from liked songs on unsaved albums (MCANS), or from unliked releases by artists you follow (MNCAS).

**Download for Windows 64-bit:** [Portable ZIP](https://github.com/thequerobin/spotifast/releases/download/v0.14.3-playlists.1/spotifast-v0.14.3-playlists.1-x86_64-pc-windows-msvc.zip).

Extract the entire ZIP into a writable folder and open `spotifast.exe`. No installer is needed. On the other computer, sign in with your own Spotify account and Spotify app Client ID using the guided setup. Playback requires Spotify Premium. Your sign-in and personal data are not included in the download.

## New

- **Generate MCANS playlists from a period of liked songs.** Tracks whose album is saved are excluded. By @thequerobin.
- **Discover unliked releases by followed artists.** MNCAS filters album/single release dates by year, month or day and excludes tracks already liked. Reissues use the date of that edition. By @thequerobin.
- **Resume playlist generation after closing the app.** Progress, pagination and pending playlist mutations are checkpointed. Pause, resume, cancel and rate-limit retries are available in the creation dialog. By @thequerobin.

## Fixed

- **Generated playlists appear in Spotifast's library.** Creation and completion confirm the Spotify playlist and repair the local library entry. By @thequerobin.
- **The creation form keeps its Close button visible.** The scroll area adapts to the longer release-date explanation. By @thequerobin.

## Preview coverage

This optimized build is for Windows x64 only and omits the optional MilkDrop visualizer. It is not digitally signed. Validation covers the Windows build, static MSVC runtime, archive integrity, command version and startup, plus automated tests with simulated Spotify responses. This fork has no configured required GitHub checks; Linux, macOS, Windows ARM, Nix and native installer packages were not validated for this preview. There are no installers or builds for other platforms in this release.
