Spotifast 0.14.3-playlists.2 reduces repeated catalog scans when creating MNCAS playlists for a short period. It searches the requested years first, reuses completed discovery results and separates consulted releases from releases matching the selected period.

## New

- **Search the requested years first.** New MNCAS jobs covering at most five calendar years use paginated artist/year track searches, verify the artist's Spotify ID and then filter the returned release dates. Tracks lead back to albums, singles and credited compilation appearances. Search results are indexed and may differ from a full catalog enumeration.
- **Reuse completed discovery after restarting.** An account-scoped disk cache stores complete artist/year results and complete fallback catalogs. Recent years and catalogs expire after 15 minutes; historical years after 24 hours. Month/day filters are reapplied when a cached year is reused. Partial, corrupt or expired results are not reused.
- **Fall back without accepting truncated search results.** A reported total of 1,000 or more results, malformed pagination or incomplete release metadata switches the current artist to full catalog discovery. An unsupported search endpoint disables further searches for that job. Rate limits keep the existing checkpoint and retry policy.

## Fixed

- **Progress distinguishes consulted releases from releases within the period.** Albums shared by several artists count once. Songs analyzed, selected and added remain separate.
- **Choose dates in Year, Month, Day order.** The aligned selectors support year-only, year/month and complete dates. Changing a month or year adjusts an invalid day automatically. The Portuguese labels are included.

Existing jobs keep their saved catalog traversal and resume without losing progress. Start a new generation to use artist/year discovery. Open periods and periods spanning more than five years use full catalogs, with cache reuse. Existing handling of imprecise release dates is unchanged and documented in the playlist-generation reference.

## Preview coverage

This is an optimized portable build for Windows x64, without the optional MilkDrop visualizer. The executable is not digitally signed. Validation includes 12 isolated native discovery/cache regression tests using the production state-machine modules and search method, repository policy checks, catalog validation, Windows cross-compilation and static inspection of PE architecture/runtime imports and ZIP integrity. Windows startup/playback, other platforms, Nix and native installer packages were not tested in this environment. Windows Clippy passed for all targets with warnings treated as errors. This fork has no configured required GitHub checks; no hosted CI run was available for this preview.

Extract the entire ZIP into a writable folder and open `spotifast.exe`. The included portable marker stores app data next to the executable. If replacing only the executable in a normal installation, do not copy the portable marker. Spotify playback requires Premium and the listener's own Spotify app setup.
