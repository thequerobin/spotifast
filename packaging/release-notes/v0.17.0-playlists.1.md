This fork integrates upstream Spotifast through `11b87b7b4f6313710244ebae6c9386496d1e57e4`, including the 0.15, 0.16 and 0.17 updates, while keeping its custom playlist generators and shared API cost manager.

## New

- **Upstream 0.17 features are available in the fork.** Windows Media Player skins, the revised Soloist setup, and the upstream playback and lyrics fixes are included. See the upstream 0.15, 0.16 and 0.17 release notes for details and contributor credits.
- **A manual Windows portable build** compiles an x64 executable with MilkDrop, runs the playlist and request-budget regression tests, verifies its runtime and version, and produces a ZIP with a SHA-256 checksum. It requires GitHub Actions to be enabled on the fork.

## Fixed

- **Custom playlist generation remains integrated after updating upstream.** MCANS, followed-artist release playlists, persisted progress, date filters, library synchronization, and API quota protection are retained.
